# Licensing

Arvolo uses an **open-core / dual-license** model.

## Open core — AGPL-3.0-only

The code in this repository (the client and the single relay) is free software
under the **GNU Affero General Public License v3.0 only** — see [`LICENSE`](LICENSE).

You may use, study, modify, and self-host it. Because it is **AGPL**, if you run a
modified version as a network service, you must make your modified source
available to that service's users. This keeps the core open even in the cloud.

## Commercial license

A separate **commercial license** is available for organizations that want to use
Arvolo **without the AGPL's obligations** — e.g. to embed it in a proprietary
product or run a modified service without publishing changes.

Business / Enterprise features (federation across relays, SSO/SAML, audit logs,
admin console, managed hosting, advanced policies) are **not** part of this
AGPL repository; if they are built, they live in a separate repository under the
commercial license.

Two things follow from that, and they are the ones worth stating plainly. What is
in this repository is AGPL-3.0 and stays that way — nothing here moves behind the
commercial license later. And the commercial licence takes nothing away from it:
it exists for organizations that cannot accept the AGPL's obligations, not to
withhold anything from the people who can.
